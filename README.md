## Titre du projet
Analyse de l'impact des réseaux sociaux sur les résultats académiques des étudiants

## Description
Ce projet porte sur l'étude de l'influence des réseaux sociaux sur la performance
scolaire des étudiants universitaires en Mauritanie.
L'objectif principal est de mesurer le temps passé sur les plateformes numériques
et de le comparer aux résultats académiques obtenus.
Pour cela, nous avons élaboré un questionnaire distribué à 50 étudiants.
Les données seront analysées avec Excel et présentées sous forme de graphiques.
Le rapport final sera rédigé en LaTeX et présenté devant le jury en fin de semestre.
